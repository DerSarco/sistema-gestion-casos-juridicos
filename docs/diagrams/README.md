# Criterios para los diagramas

## Diagramas requeridos

- Casos de uso.
- Clases.
- Secuencia.
- Despliegue.

## Organización

- `src/`: archivo fuente editable de cada diagrama.
- `rendered/`: exportaciones en SVG y, cuando el informe lo requiera, PNG de
  resolución suficiente para impresión.

## Reglas de elaboración

1. Crear y asignar un issue antes de elaborar un diagrama.
2. Indicar el objetivo, alcance, versión y requisitos relacionados.
3. Usar la misma terminología definida en el SRS.
4. Revisar el diagrama contra los criterios de aceptación del issue.
5. Versionar conjuntamente la fuente editable y la exportación.
6. Agregar título y fuente en la versión destinada al informe académico.

La herramienta y notación exactas se registrarán como una decisión técnica
antes de crear el primer diagrama. Se priorizará un formato reproducible y apto
para control de versiones.
